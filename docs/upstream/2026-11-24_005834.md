Bluetooth: L2CAP: Don't call the status callback from the TX processor

When an LE credit-based channel uses its last credit, chan_take_credit()
calls the channel's status callback from the TX processor, inside the
pass that holds the host lock. A callback that calls an API that waits
for an HCI command, such as bt_conn_disconnect() or

peer has given credits meanwhile, the channel is reported as sendable.
